### 🤖 RPA & Python — Automação de Processos
| Projeto | Descrição | Impacto |
|---|---|---|
| **Consulta em Massa de Cadastros (API + Web Scraping)** | Robô Python que consulta Inscrições Estaduais e CNPJs em larga escala, com estratégia dupla (API de alta velocidade + RPA como fallback). | +1 milhão de registros processados |
| **Saneamento e Validação de XML Fiscal** | Robôs que corrigem, estruturam e validam automaticamente arquivos XML de notas fiscais fora do padrão exigido pelo fisco. | Elimina rejeições por arquivo inválido |
| **Automação de Escrituração Fiscal (SAP)** | Robôs em Python/VBA + SAP Script para internalizar e emitir notas fiscais automaticamente no ERP. | Escrituração manual → automática |
| **Inserção Automatizada de Blocos em Obrigações Acessórias** | Robô que lê base de dados e insere registros ausentes em declarações fiscais para retificação. | Regularização em escala |
| **Atualização de Status em Workflow** | RPA para tratamento de alto volume de notas fiscais em sistema de workflow. | Precisão + velocidade |
